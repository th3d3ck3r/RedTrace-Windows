# Changelog

## 2.7.0
- Added ConPTY-backed PowerShell, Command Prompt, and WSL Runner sessions.
- Added direct terminal keyboard/paste input and retained quick commands, history, shell selection, restart, clear, and Common Commands.
- Renamed CODEX to CHATGPT and added shared Minimal, Normal, and Verbose local activity views.
- Expanded hook records to retain observable non-command tool activity.
- Added Windows Actions build, publish, executable verification, and artifact upload.

## 2.6.x
- Added Common Commands, responsive system-monitor/card columns, per-thread CPU display, rounded Windows styling, and corrected card scrolling/resizing behavior.

## 2.5.x
- Added tabs/cards dashboard layouts, dedicated windows, moveable/resizable cards, compact title-bar metrics, theme controls, and tray/background support.

## 2.0.0
- Introduced the native WinUI 3 RedTrace Windows companion with WATCH, RUN, CODEX, BTOP, PowerShell, CMD, WSL, local hooks, and system monitoring.
